PicX@JIE

一个基于 GitHub 的图床工具。没有复杂的配置，也不依赖服务器，只是把图片安安静静地存好，返回一个干净的链接

为什么做这个

写博客、记笔记、整理文档时，图片总是件麻烦事。本地图片换台设备就丢了，第三方图床又总担心哪天跑路。PicX 就是把这件事变得简单、稳定、可控

它是怎么工作的

  • 图片存储在 GitHub 仓库里，数据始终在自己自己手里
  • 通过 EdgeOne Pages 分发，在全球各地都能比较快地加载
  • 支持拖拽上传，生成的链接可以直接贴在 Markdown 里

适合谁用

适合那些对内容有长期保存需求的人：写作者、开发者、喜欢折腾笔记的人，追求稳定，不想到处搬家
