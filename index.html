CDN@JIE

CDN 分发静态资源，GitHub 储存 + EdgeOne Pages 配置。仓库是个大杂烩，兼顾 PicX：一个基于 GitHub 的图床工具；也放了一些静态网页进去，方便管理

为什么做这个

写博客、记笔记、整理文档时，图片总是件麻烦事。本地图片换台设备就丢了，第三方图床又总担心哪天跑路。PicX 就是把这件事变得简单、稳定、可控。但又不只是图床那么简单，利用 Git 很方便地上传一些静态资源如 JS、CSS 文件到 GitHub，这样通过 CDN 分发，网站可以跑得很快

它是怎么工作的

  • 图片存储在 GitHub 仓库里，数据始终在自己自己手里
  • 通过 EdgeOne Pages 分发，在全球各地都能比较快地加载
  • 支持拖拽上传，生成的链接可以直接贴在 Markdown 里
