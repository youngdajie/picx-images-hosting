关于这个项目

CDN 分发静态资源，GitHub 储存 + EdgeOne Pages 配置。仓库是个大杂烩，兼顾 PicX：一个基于 GitHub 的图床工具；也放了一些静态网页进去，方便管理。

写博客、记笔记、整理文档时，图片总是件麻烦事。本地图片换台设备就丢了，第三方图床又总担心哪天跑路。PicX 就是把这件事变得简单、稳定、可控。

打开 PicX 图床

为什么做这个

  • 图片存储在 GitHub 仓库，数据始终在自己手里
  • 通过 EdgeOne Pages 分发，全球加载飞快
  • 支持拖拽上传，生成的链接可直接贴在 Markdown 里

它是怎么工作的

  • 利用 Git 很方便地上传静态资源（JS、CSS）到 GitHub
  • 通过 CDN 分发，让网站跑得更快
  • 开源项目，代码透明，安全可控
